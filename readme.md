# synt_data

Репозиторий для работы с данными по диалогам.

## Структура

### `data/` — сырые данные

Содержит исходные данные в формате Excel (`.xlsx`). Например, файлы с диалогами для анализа.

### `docs/` — требования и идеи

Содержит документы с требованиями, описанием идеи и рекомендациями по тому, какие данные стоит создать и в каком виде.

### `plan/` — контекст действий

Содержит контекст и инструкции о том, как следует действовать при выполнении тех или иных задач. Это правила и подходы, которым нужно придерживаться при работе с проектом.
