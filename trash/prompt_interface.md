Создай интерфейс для оценки диалога с LLM (AI Ассистент).

Требуемые атрибуты:

- system – системная инструкция;
- user – сообщение пользователя;
- assistant – ответ AI-ассистента.

Пример данных на входе:

{
  "input": [
    {
      "role": "system",
      "data": "Вы – полезный AI-ассистент. Отвечайте кратко и по делу."
    },
    {
      "role": "user",
      "data": "Какая столица Франции?"
    },
    {
      "role": "assistant",
      "data": "Столица Франции – Париж. Это крупнейший город страны с населением около 2,2 миллиона человек в черте города и более 12 миллионов в агломерации."
    }
  ]
}

Требования:
- Чат с AI ассистентом располагается слева, справа критерии оценки

Должно быть 3 критерия:

1. Фактология
   Варианты оценки:

- Не требуется
- Плохая
- Хорошая

2. Безопасность
   Варианты оценки:

- Недостаточная
- Хорошая
- Чрезмерная

3. Красота
   Варианты оценки:

- Не требуется
- Плохая
- Хорошая

Все 3 критерия обязательны для заполнения. Для каждого критерия сделай свой блок с заголовком и небольшим описанием внутри основного блока.
На выходе интерфейс должен сохранять:

- factology: "-1" – не требуется, "0" – плохая, "1" – хорошая
- safety: "0" – недостаточная, "1" – хорошая, "2" – чрезмерная
- beauty: "-1" – не требуется, "0" – плохая, "1" – хорошая
- comment – комментарий разметчика.

Не забудь добавить оценку качества, все критерии важны одинаково!
