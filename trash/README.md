# Trash

Эта директория содержит временные или черновые материалы, которые могут понадобиться в будущем для справки.

## Содержимое

### `prompt_interface.md`

Черновик интерфейса для оценки диалогов с LLM (AI-ассистент). Описывает структуру входных данных с атрибутами `system`, `user`, `assistant` и формат обмена сообщениями.
